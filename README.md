# 项目审查顾问 (Project Review Advisor)

一个强大的 Claude Code 插件，通过智能问答帮助您深度审查和完善项目规划。

**🌟 核心特色**：采用 **Manus 风格持久化规划模式** (Inspired by https://github.com/Dream4tack/planning-with-files)

## 🎯 功能特性

- **三文件工作系统**：使用 `task_plan.md` + `notes.md` + `[deliverable].md` 持久化审查进度
- **智能项目分析**：自动扫描项目结构，识别项目类型和技术栈
- **多维度审查**：涵盖架构、功能、安全、性能、测试等多个方面
- **动态问答系统**：根据项目特点生成针对性问题，基于回答动态调整
- **核心文档维护**：生成并维护项目核心规划文档，而非静态报告
- **灵活的审查深度**：从快速审查到深度专项审查，满足不同需求

## 🗂️ 三文件模式说明

本插件遵循 Manus 的**"文件系统作为工作记忆"**理念：

| 文件 | 用途 | 更新频率 |
|------|------|----------|
| `*_review_plan.md` | 审查任务计划，阶段跟踪 | 每个阶段切换时 |
| `*_review_notes.md` | 发现记录，问答归档 | 每次问答后立即更新 |
| `PROJECT_PLANNING.md` | 最终项目规划文档 | 审查结束时生成 |

**核心优势**：
- ✅ 所有发现持久化到文件，不依赖上下文窗口
- ✅ 使用 checkbox `[x]` 跟踪进度，防止目标漂移
- ✅ 定期重读 plan 文件保持目标对齐
- ✅ 追加式记录，保留审查历史

## 📦 安装

这个插件基于 **Claude Code Slash Commands**，提供两种安装方式：

### 方式一：全局安装（推荐）

安装到用户全局目录，在**任何项目**中都可以使用审查命令。

**Linux / macOS**：
```bash
# 克隆或下载本项目
git clone https://github.com/Dream4tack/ai-interview.git
cd ai-interview

# 运行安装脚本
./install.sh
```

**Windows (PowerShell)**：
```powershell
# 克隆或下载本项目
git clone https://github.com/Dream4tack/ai-interview.git
cd ai-interview

# 运行安装脚本
.\install.ps1
```

安装脚本会：
- ✅ 自动检测审查命令
- ✅ 备份现有命令（如果有）
- ✅ 复制命令到 `~/.claude/commands/review/`
- ✅ 显示可用命令列表

**卸载**：
```bash
# Linux / macOS
./uninstall.sh

# Windows
.\uninstall.ps1
```

### 方式二：项目本地安装

仅在特定项目中使用审查命令。

```bash
# 在你的项目根目录
mkdir -p .claude/commands
cp -r /path/to/ai-interview/.claude/commands/review .claude/commands/
```

### 更新到最新版本

```bash
cd ai-interview
git pull
./install.sh  # 或 .\install.ps1 (Windows)
```

## 🚀 快速开始

### 1. 完整项目审查

进行全面的交互式项目审查（15-30个问题）：

```
/review:start
```

Claude 会：
1. **初始化三文件系统**：
   - 创建 `project_review_plan.md` - 6个审查阶段，checkbox 跟踪进度
   - 创建 `project_review_notes.md` - 记录所有问答和发现

2. **项目发现**：
   - 自动扫描并分析项目结构
   - 识别项目类型（Web应用、API、数据分析等）
   - 将发现记录到 notes 文件

3. **交互式访谈**（持久化进度）：
   - 提出针对性问题，覆盖 8 大维度
   - 每收到回答立即更新 notes 文件
   - 每 3-5 个问答重读 plan 确认目标对齐
   - 根据回答动态调整后续问题

4. **生成核心规划文档**：
   - 基于 notes 中的发现
   - 生成 `PROJECT_PLANNING.md`
   - 包含定位、架构、功能、风险、建议、行动计划
   - 格式可被 `planningwithfile` 技能进一步维护

**审查覆盖维度**：
- 项目定位与目标
- 技术架构
- 功能规划
- 代码质量
- 安全与合规
- 测试策略
- 部署与运维
- 团队与流程

**生成文件**：
- ✅ `project_review_plan.md` - 审查任务追踪
- ✅ `project_review_notes.md` - 完整发现记录
- ✅ `PROJECT_PLANNING.md` - 最终项目规划

**适用场景**：
- 项目初期，明确核心需求
- 重大决策前，系统性评估
- 项目里程碑，全面复盘

### 2. 快速审查

进行快速但聚焦的审查（5-10个核心问题，10-15分钟）：

```
/review:quick
```

Claude 会：
1. **初始化简化三文件**：
   - 创建 `quick_review_plan.md` - 4个快速阶段
   - 创建 `quick_review_notes.md` - 精简记录格式

2. **快速扫描**（1-2分钟）：
   - 识别项目类型和技术栈
   - 更新 notes 记录项目快照

3. **核心提问**（8-10分钟）：
   - 5-10个最关键问题
   - 聚焦定位、技术、风险
   - 实时更新 notes

4. **快速规划**：
   - 生成 `PROJECT_QUICK_PLAN.md`
   - 2-3个优势，2-3个风险
   - 3-5个优先建议

**生成文件**：
- ✅ `quick_review_plan.md` - 快速审查追踪
- ✅ `quick_review_notes.md` - 精简发现
- ✅ `PROJECT_QUICK_PLAN.md` - 快速规划文档

**适用场景**：
- 时间有限但需要快速反馈
- 项目中期快速检查
- 新成员快速了解项目

### 3. 生成审查报告

基于之前的审查对话生成详细报告：

```
/review:report
```

Claude 会回顾本次会话的所有审查对话，生成包含13个章节的完整报告，保存为 `PROJECT_REVIEW_REPORT.md`。

报告包含：
- 执行摘要和评分
- 项目概况和分析
- 架构、功能、安全等专项审查
- 问答记录
- 发现和见解
- 按优先级排序的改进建议
- 详细的行动计划

## 💡 使用技巧

### 1. 充分准备

在开始审查前：
- 确保项目关键文件已创建（README、配置文件等）
- 整理核心代码结构
- 准备好回答项目愿景和技术选型的理由

### 2. 诚实回答

- 如实回答当前状态，不要美化
- 承认不确定的地方，Claude 会帮助你思考
- 主动提出你的担忧和疑问

### 3. 深入对话

- 不要只是简短回答，提供上下文
- 如果问题触发了新的思考，分享出来
- 对建议提出你的看法，进行双向讨论

### 4. 迭代改进

- 根据审查报告实施改进
- 定期重新审查（3-6个月）
- 跟踪行动计划的执行情况

## 🎨 自定义

### 修改问题模板

编辑 `.claude/commands/review/*.md` 文件来自定义：
- 问题类别和数量
- 提问风格和语气
- 报告格式和章节
- 审查深度和侧重点

### 添加新的审查类型

创建新的命令文件，例如：

```bash
# 创建数据库审查命令
cat > .claude/commands/review/database.md << 'EOF'
# 数据库专项审查

你是数据库专家。对当前项目的数据库设计进行深度审查...

[自定义审查流程和问题]
EOF
```

然后使用：
```
/review:database
```

## 🤔 常见问题

### Q: 审查需要多长时间？
- **快速审查**：10-15分钟
- **完整审查**：30-60分钟
- **专项审查**：20-40分钟

### Q: 什么时候应该做审查？
- 项目启动阶段
- 做重大技术决策前
- 遇到棘手问题时
- 项目里程碑节点
- 定期的技术复盘

### Q: 审查报告如何使用？
- 作为项目文档的一部分
- 指导技术决策
- 制定改进计划
- 向利益相关者汇报
- 团队知识传承

### Q: 可以审查任何类型的项目吗？
是的！插件支持：
- Web应用（前端/后端/全栈）
- API服务
- 移动应用
- 数据科学/机器学习项目
- 工具和库项目
- 其他类型项目

Claude 会根据项目类型自动调整问题。

### Q: 审查会修改我的代码吗？
不会。审查过程只是：
1. 读取项目文件进行分析
2. 与你交互式问答
3. 生成审查报告

完全不会修改任何代码或配置。
