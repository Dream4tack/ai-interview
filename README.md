# 项目审查顾问 (Project Review Advisor)

一个强大的 Claude Code 插件，通过智能问答帮助您深度审查和完善项目规划。

## 🎯 功能特性

- **智能项目分析**：自动扫描项目结构，识别项目类型和技术栈
- **多维度审查**：涵盖架构、功能、安全、性能、测试等多个方面
- **动态问答系统**：根据项目特点生成针对性问题，基于回答动态调整
- **专业审查报告**：生成结构化的 Markdown 审查报告，包含问题分析和改进建议
- **灵活的审查深度**：从快速审查到深度专项审查，满足不同需求

## 📦 安装

这个插件基于 **Claude Code Slash Commands**，无需额外安装，只需将命令文件放在项目的 `.claude/commands/review/` 目录下即可。

### 自动安装（如果你已经克隆了这个项目）

插件已经在当前项目中配置好了！直接使用即可。

### 手动安装到其他项目

将 `.claude/commands/review/` 目录复制到你的项目中：

```bash
# 在你的项目根目录
mkdir -p .claude/commands
cp -r /path/to/ai-interview/.claude/commands/review .claude/commands/
```

## 🚀 快速开始

### 1. 完整项目审查

进行全面的交互式项目审查（15-30个问题）：

```
/review:start
```

Claude 会：
1. 自动扫描并分析项目结构
2. 识别项目类型（Web应用、API、数据分析等）
3. 提出针对性问题，覆盖：
   - 项目定位与目标
   - 技术架构
   - 功能规划
   - 安全与合规
   - 质量保证
   - 部署与运维
4. 根据你的回答动态调整后续问题
5. 生成完整的审查报告

**适用场景**：
- 项目初期，完善项目规划
- 重大决策前，系统性评估
- 项目里程碑，全面复盘

### 2. 快速审查

进行快速但聚焦的审查（5-10个核心问题，10-15分钟）：

```
/review:quick
```

Claude 会：
1. 快速扫描项目
2. 提出5-10个最关键的问题
3. 快速识别主要风险和机会
4. 生成简洁的审查报告

**适用场景**：
- 时间有限但需要快速反馈
- 项目中期快速检查
- 新成员快速了解项目

### 3. 生成审查报告

基于之前的审查对话生成详细报告：

```
/review:report
```

Claude 会回顾本次会话的所有审查对话，生成包含13个章节的完整报告，保存为 `PROJECT_REVIEW_REPORT.md`。

报告包含：
- 执行摘要和评分
- 项目概况和分析
- 架构、功能、安全等专项审查
- 问答记录
- 发现和见解
- 按优先级排序的改进建议
- 详细的行动计划

## 💬 问答记录

## 💡 使用技巧

### 1. 充分准备

在开始审查前：
- 确保项目关键文件已创建（README、配置文件等）
- 整理核心代码结构
- 准备好回答项目愿景和技术选型的理由

### 2. 诚实回答

- 如实回答当前状态，不要美化
- 承认不确定的地方，Claude 会帮助你思考
- 主动提出你的担忧和疑问

### 3. 深入对话

- 不要只是简短回答，提供上下文
- 如果问题触发了新的思考，分享出来
- 对建议提出你的看法，进行双向讨论

### 4. 迭代改进

- 根据审查报告实施改进
- 定期重新审查（3-6个月）
- 跟踪行动计划的执行情况

## 🎨 自定义

### 修改问题模板

编辑 `.claude/commands/review/*.md` 文件来自定义：
- 问题类别和数量
- 提问风格和语气
- 报告格式和章节
- 审查深度和侧重点

### 添加新的审查类型

创建新的命令文件，例如：

```bash
# 创建数据库审查命令
cat > .claude/commands/review/database.md << 'EOF'
# 数据库专项审查

你是数据库专家。对当前项目的数据库设计进行深度审查...

[自定义审查流程和问题]
EOF
```

然后使用：
```
/review:database
```

## 🤔 常见问题

### Q: 审查需要多长时间？
- **快速审查**：10-15分钟
- **完整审查**：30-60分钟
- **专项审查**：20-40分钟

### Q: 什么时候应该做审查？
- 项目启动阶段
- 做重大技术决策前
- 遇到棘手问题时
- 项目里程碑节点
- 定期的技术复盘

### Q: 审查报告如何使用？
- 作为项目文档的一部分
- 指导技术决策
- 制定改进计划
- 向利益相关者汇报
- 团队知识传承

### Q: 可以审查任何类型的项目吗？
是的！插件支持：
- Web应用（前端/后端/全栈）
- API服务
- 移动应用
- 数据科学/机器学习项目
- 工具和库项目
- 其他类型项目

Claude 会根据项目类型自动调整问题。

### Q: 审查会修改我的代码吗？
不会。审查过程只是：
1. 读取项目文件进行分析
2. 与你交互式问答
3. 生成审查报告

完全不会修改任何代码或配置。
