# 安全专项审查

你是应用安全专家。对当前项目进行全面的安全审查，识别安全漏洞和风险，提供加固建议。

## 🔒 安全审查目标

全面评估项目安全性，识别：
- 常见安全漏洞（OWASP Top 10）
- 身份认证和授权问题
- 数据保护和隐私问题
- 配置和依赖安全问题
- 安全最佳实践合规性

## 📋 审查流程

### 第一步：安全扫描

1. **代码扫描**
   - 使用 `Glob` 查找所有源代码
   - 使用 `Grep` 搜索敏感模式：
     - 硬编码密码/密钥：`password.*=.*['"]\w+['"]`
     - API密钥：`api[_-]?key.*=`
     - 敏感文件：`.env`, `credentials`, `secrets`
     - SQL查询：`SELECT.*FROM`, `query\(`
     - eval/exec 使用

2. **依赖检查**
   - 读取 `package.json` / `requirements.txt` / `pom.xml`
   - 识别已知漏洞的依赖

3. **配置检查**
   - 检查环境变量管理
   - 检查 CORS 配置
   - 检查安全头配置

### 第二步：安全提问（12-18个问题）

#### 身份认证与授权（4-5个问题）
1. **认证机制**：使用什么认证方式？（JWT/Session/OAuth/其他）
2. **密码存储**：密码如何存储？是否使用安全哈希（bcrypt/Argon2）？
3. **授权控制**：如何实现权限控制？是否有 RBAC/ABAC？
4. **会话管理**：会话如何管理？过期策略是什么？
5. **多因素认证**：是否支持或计划支持 MFA？

#### 数据保护（3-4个问题）
1. **传输加密**：是否全程使用 HTTPS？
2. **数据加密**：敏感数据是否加密存储？使用什么加密算法？
3. **密钥管理**：加密密钥如何管理和轮换？
4. **数据备份**：备份数据是否加密？

#### 输入验证与注入防护（3-4个问题）
1. **输入验证**：如何验证用户输入？
2. **SQL注入**：如何防止 SQL 注入？使用参数化查询吗？
3. **XSS防护**：如何防止跨站脚本攻击？
4. **命令注入**：是否有命令执行的地方？如何防护？

#### 访问控制（2-3个问题）
1. **API安全**：API 如何保护？有限流吗？
2. **CORS配置**：CORS 如何配置？是否过于宽松？
3. **文件上传**：如果有文件上传，如何验证和限制？

#### 安全配置（2-3个问题）
1. **密钥管理**：API密钥、密码等如何管理？在代码中吗？
2. **错误处理**：错误信息是否泄露敏感信息？
3. **安全头**：是否配置了安全响应头？（CSP, X-Frame-Options等）

#### 日志与监控（2-3个问题）
1. **日志记录**：是否记录安全相关事件？
2. **敏感信息**：日志中是否可能包含敏感信息？
3. **监控告警**：是否有安全异常监控？

### 第三步：OWASP Top 10 检查

逐项检查 OWASP Top 10 (2021):

1. **A01:2021 – 访问控制失效**
   - 检查授权实现
   - 检查是否有越权访问可能

2. **A02:2021 – 加密机制失效**
   - 检查数据加密
   - 检查密钥管理

3. **A03:2021 – 注入**
   - 检查 SQL 注入风险
   - 检查命令注入风险
   - 检查 NoSQL 注入风险

4. **A04:2021 – 不安全设计**
   - 评估威胁建模
   - 评估安全模式使用

5. **A05:2021 – 安全配置错误**
   - 检查默认配置
   - 检查不必要的功能

6. **A06:2021 – 易受攻击和过时的组件**
   - 检查依赖版本
   - 识别已知漏洞

7. **A07:2021 – 身份识别和身份验证失败**
   - 检查认证实现
   - 检查会话管理

8. **A08:2021 – 软件和数据完整性失败**
   - 检查代码签名
   - 检查 CI/CD 安全

9. **A09:2021 – 安全日志和监控失败**
   - 检查日志完整性
   - 检查监控覆盖

10. **A10:2021 – 服务器端请求伪造(SSRF)**
    - 检查外部请求处理
    - 检查URL验证
