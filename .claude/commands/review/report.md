# 生成项目审查报告

你是专业的项目审查报告生成专家。基于之前的交互式审查对话，生成一份全面、专业、可执行的项目审查报告。

## 📋 报告生成任务

### 第一步：回顾对话历史

仔细回顾本次会话中的所有项目审查相关对话：
- 用户提供的项目信息
- 提出的问题和用户的回答
- 讨论中识别的问题和风险
- 已经给出的建议

### 第二步：补充项目分析（如果之前没做）

如果还没有进行项目扫描，现在进行：
1. 使用 `Glob` 扫描项目结构
2. 使用 `Read` 读取关键文件（README、配置文件、主要代码）
3. 识别项目类型、技术栈、规模

### 第三步：生成完整报告

生成包含以下所有章节的完整报告：

```markdown
# 项目审查报告

> **项目名称**：[项目名称]
> **审查日期**：[当前日期]
> **审查类型**：[完整审查 / 快速审查]
> **项目阶段**：[规划 / 开发 / 测试 / 生产]
```

6. **专业性**：语言专业但易懂
